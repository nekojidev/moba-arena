# PWA (Lab 8)

Перевірено 2026-11-20 одноразовим скриптом на Playwright (Chromium, постійний профіль) проти справжнього сервера в контейнері `moba-arena:lab8` на `http://localhost:3080`. Скрипт у репозиторій не додано. На телефоні не перевірялося.

## Що додано

| Файл                                 | Навіщо                                                                                 |
| ------------------------------------ | -------------------------------------------------------------------------------------- |
| `client/public/manifest.webmanifest` | назва, `start_url` і `scope` `/`, `standalone`, `landscape`, кольори `#0b100d`, іконки |
| `client/public/icons/icon.svg`       | малюнок іконки: зелений маг із посохом на колі арени                                   |
| `client/public/icons/*.png`          | 192, 512, maskable 512, apple-touch-icon 180                                           |
| `client/scripts/make-icons.mjs`      | робить PNG з SVG через Chromium із Playwright                                          |
| `client/public/sw.js`                | service worker                                                                         |
| `client/src/pwa.ts`                  | реєструє воркер лише у продакшн-збірці (`import.meta.env.PROD`)                        |
| `client/index.html`                  | `manifest`, `theme-color`, іконки, мета-теги для iOS                                   |

Іконки перегенерувати: `node client/scripts/make-icons.mjs`.

## Як працює service worker

| Запит                                                                 | Стратегія                                              |
| --------------------------------------------------------------------- | ------------------------------------------------------ |
| `/ws`, `/api/*`, `/health`, `/ready`, `/metrics`                      | воркер не втручається                                  |
| сторінки (HTML)                                                       | спершу мережа; кеш — лише коли мережі немає            |
| `/assets/ім'я-ХЕШ.js`                                                 | спершу кеш (вміст файла з хешем у назві не змінюється) |
| спрайти, звуки, JSON, іконки                                          | одразу з кешу, у фоні оновлення                        |
| не GET, інший origin, запити з `Range` чи з параметрами до `/assets/` | воркер не втручається                                  |

Під час встановлення воркер нічого не кешує наперед: у кеш `moba-arena-v1` потрапляє лише те, що сторінка завантажила сама. Старі кеші з префіксом `moba-arena-` видаляються на `activate`. У завданні для API названо «спершу мережа» і водночас «не чіпати `/api/*`»; обрано друге, тож список кімнат ніколи не береться з кешу.

Користь є навіть без офлайну: сервер віддає статику з `cache-control: no-cache`, тому без воркера браузер щоразу звертається до сервера за кожним файлом.

## Потрібна зміна у файлі сервера

У `server/src/static.ts` немає типу для `.webmanifest`, тому маніфест віддається як `application/octet-stream`. Chromium його приймає (помилок встановлення немає), але правильний тип — `application/manifest+json`. У таблицю `MIME` треба додати один рядок:

```ts
  '.webmanifest': 'application/manifest+json; charset=utf-8',
```

## Чого не перевірено й обмеження

- Справжнє встановлення не перевірялося ні на телефоні, ні на комп'ютері: є лише порожній список помилок встановлення від Chromium у режимі без вікна. Екран запуску, вигляд maskable-іконки в різних оболонках Android і блокування альбомної орієнтації видно тільки на пристрої.
- Safari на iOS не перевірявся взагалі. Там діють лише `apple-touch-icon` і мета-теги, `orientation` з маніфесту iOS ігнорує.
- Гра керується клавіатурою. На телефоні застосунок встановиться, відкриється і покаже лобі, але грати без клавіатури не можна: екранних кнопок немає.
- Для встановлення потрібен HTTPS (або `localhost`). За адресою на кшталт `http://192.168.x.x:3000` воркер не зареєструється.
- Без сервера гра не працює: офлайн відкривається лише вже бачена сторінка зі станом «немає з’єднання».
- Версію кешу (`moba-arena-v1` у `sw.js`) треба змінювати вручну. Скрипти з новим хешем після оновлення завантажаться самі, але старі файли лишаються в кеші, доки номер не змінено.
- Спрайти й звуки оновлюються у фоні, тому після їх заміни гравець побачить нові лише з другого завантаження.
